# AGENTS.md

## Проект

Одностраничный статический лендинг с анимацией конфетти на Canvas.
Репозиторий: https://github.com/Abergaz/test

## Стек

- HTML5 — семантическая разметка
- CSS3 — без препроцессоров и CSS-фреймворков
- JavaScript ES2020+ — без сборщиков и npm-зависимостей
- Canvas 2D API — анимация частиц
- Git / GitHub — ветка `main`
- Проверка — браузер Chromium и DevTools

Новые зависимости, библиотеки и инструменты сборки добавляются только
по явному согласованию.

## Разделение языков по файлам

- `index.html` — только разметка и подключения.
- `styles/*.css` — стили.
- `scripts/*.js` — скрипты.
- Встроенные `<style>` и `<script>` без `src` не используем: каждый язык
  живёт в своём файле и подключается там, где нужно.
- Исключение допустимо только по явному согласованию и с пояснением
  в комментарии.

## Комментарии

- Все комментарии, описания и документация — на русском языке.
- Имена переменных, функций и файлов — на английском (латиницей), как
  принято в языке.
- Комментарий объясняет «зачем», а не пересказывает «что» делает код.

## Документирование кода

Код должен быть пригоден для автоматической сборки документации.

- **JavaScript:** JSDoc-блок перед каждой функцией и модулем — `@param`,
  `@returns`, `@throws`, при необходимости `@example`. Для структур данных
  используется `@typedef`. Генерация документации выполняется `jsdoc`
  (появится вместе с dev-зависимостями).
- **CSS:** секции оформляются заголовочными комментариями
  `/* === Блок: назначение === */`, переменные `:root` описываются построчно.
- **HTML:** смысловые блоки помечаются комментариями
  `<!-- Блок: назначение -->`.

## Функции

- Одна функция — одна задача.
- Ориентир: до 30–40 строк и не более 3–4 параметров.
- Если функция разрастается — делим её на части с понятными именами.
- Имя функции описывает действие: `spawnParticles`, `resizeCanvas`,
  `drawParticle`.
