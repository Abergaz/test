## Когда применять

Перед коммитом, а также после изменений в `scripts/confetti.js`.

## Порядок

1. Поднять локальный сервер в корне проекта и открыть страницу через навык
   `browser`.
2. Дождаться появления контента: анимация `rise-in` занимает около 1,3 с,
   до неё заголовок и кнопка прозрачны.
3. **Консоль:** ошибок быть не должно.
4. **Сеть:** запросы только к `/`, `/styles/main.css`, `/scripts/confetti.js`.
   Внешних доменов быть не должно.
5. **Клик по кнопке:** частицы появляются и разлетаются по ширине окна.
6. **Лимит частиц:** десять быстрых кликов не должны давать больше 600 частиц.
   Для замера временно добавить `window.__confettiCount = () => particles.length`
   и обязательно удалить после проверки.
7. **Клавиатура:** фокус на кнопке виден; Enter и Пробел запускают конфетти
   из центра кнопки, а не из угла экрана.
8. **Reduced motion:** при переключении медиазапроса без перезагрузки
   следующий клик даёт 50 частиц вместо 170.
9. **Метрики:** DOMContentLoaded, load, FCP, CLS, объём переданных файлов,
   число узлов DOM, FPS в покое и с конфетти.
10. **Lighthouse:** Accessibility, Best Practices, SEO.

## Пороги

- FPS с конфетти не ниже FPS в покое минус 10%.
- CLS равен 0.
- Встроенный Lighthouse не выдаёт оценку Performance — вместо неё опираться
  на метрики загрузки и FPS.
- Accessibility, Best Practices, SEO — по 100.
